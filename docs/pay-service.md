# 支付宝 SkillPay 发布指南

Grill My Research 于 2026-11-03 在支付宝 SkillPay 上架，首发包为 `grill-my-research-0.1.0.zip`。[公开购买页](https://skillpay.alipay.com/user/product?merchantId=2088702084897672&productId=P0806000211847585)

商品采用 **¥9.90 一次买断**。支付宝 SkillPay 负责收款并向买家交付完整 Skill。安装后，买家可以在自己的 Agent 中永久使用所购版本，无需为每次生成提示词付费。

## 更新已有商品

1. 按[版本与发布](releasing.md)构建并核对本次要发布的 ZIP。
2. 打开[支付宝 SkillPay 商品管理](https://skillpay.alipay.com/creator/products)，找到 Grill My Research（商品 ID `P0806000211847585`），选择「编辑商品信息」。
3. 上传本次构建的 ZIP，按新版本的实际能力更新描述。核对商品名称、买断制和 ¥9.90 价格后提交审核。
4. 等商品管理页显示「销售中」，再打开公开购买页核对名称、售卖模式和价格。README 中的购买链接始终指向买家看到的商品页。
